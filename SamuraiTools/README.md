# SamuraiTools
These are tools only available on VDO.Samurai.

## How to use SamuraiTools
First you'll need to know what SamuraiTool you will be using. For example, we will use the [links page](https://github.com/detectivesheepy/vdo.samurai/blob/develop/SamuraiTools/links). Then, type vdosamurai.vercel.app/samuraitools in your browser, followed by another / and then the name of the tool you are using. In this case, links.html. So your link should look something like: vdosamurai.vercel.app/samuraitools/links.html.
